# Bouncing Objects SFML Assignment

NOTE: This README was auto-generated by Claude. 
Prompt: Briefly describe this project formatted as a markdown file.

A small C++/SFML program where a circle and a rectangle bounce around the
window, reversing direction whenever they hit an edge. The goal of the
assignment is to practice C++ class templates and file separation for classes:
a single `Shape<T>` template drives any SFML shape, with declarations kept in a
header (protected by include guards) and definitions in a separate source file,
made linkable through explicit template instantiation so the compiler generates
the code for each shape type.
 
SFML is downloaded and built automatically during configuration
(via CMake's `FetchContent`), so you don't need to install SFML yourself — 
the same build commands work on every platform.

## Requirements
 
- A C++17-capable compiler (MSVC, GCC, or Clang)
- CMake 3.28 or newer
- Git

## Building and Running

Clone the repository and build:
 
```bash
git clone https://github.com/nicolasorobia/BouncingObjects.git
cd BouncingObjects
cmake -B build
cmake --build build
```
 
Then run the program:
 
```bash
# macOS / Linux
./build/BouncingObjects
 
# Windows (Visual Studio generator places the binary in a config subfolder)
.\build\Debug\BouncingObjects.exe
```
 
The window opens with the circle centered; it starts bouncing immediately.
Close the window to exit.
