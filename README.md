# Bouncing Objects SFML Assignment

NOTE: This README was auto-generated by Claude. Prompt: Briefly describe this project in markdown profile.

A small C++/SFML program: a red circle bounces around the window, reversing direction each time it touches an edge. It's a minimal SFML demo built to run the same way on Windows, macOS, and Linux.
 
SFML is downloaded and built automatically during configuration (via CMake's `FetchContent`), so you don't need to install SFML yourself — the same build commands work on every platform.

## Requirements
 
- A C++17-capable compiler (MSVC, GCC, or Clang)
- CMake 3.28 or newer
- Git

## Building and Running

Clone the repository and build:
 
```bash
git clone https://github.com/nicolasorobia/BouncingObjects.git
cd BouncingObjects
cmake -B build
cmake --build build
```
 
Then run the program:
 
```bash
# macOS / Linux
./build/BouncingObjects
 
# Windows (Visual Studio generator places the binary in a config subfolder)
.\build\Debug\BouncingObjects.exe
```
 
The window opens with the circle centered; it starts bouncing immediately.
Close the window to exit.
